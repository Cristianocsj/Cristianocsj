## ⭐ Projetos em Destaque

### 🎮 Crash Market Survivor — Cristian Financial Group
**O problema:** unir educação financeira com gamificação, em um produto único e publicável.
**A solução:** plataforma web institucional com aulas em vídeo, dicas financeiras e dois jogos: um arcade 2D ("The Floor is Bear Market") e uma build **Unity WebGL**, ambos integrados ao mesmo site.

**Destaques técnicos:**
- Jogo 2D renderizado com **PixiJS** (game loop, colisão, HUD, bots com IA simples)
- Build **Unity WebGL** integrada ao site, com canvas responsivo e controles de teclado
- Deploy completo via **Firebase Hosting**, com rotas de compatibilidade e página 404 customizada

🔗 [Código-fonte](https://github.com/Cristianocsj/Crash_Market_Survivor) • 🌐 [Aplicação ao vivo](https://stock-markets-site.web.app/)

---

### 💰 My Money Flow
**O problema:** organizar e visualizar as próprias finanças pessoais de forma simples e acessível.
**A solução:** aplicação web de controle financeiro pessoal, com cadastro/login de usuário e gestão de receitas e despesas.

**Destaques técnicos:**
- Desenvolvido em **TypeScript**
- Construído com apoio de **LLM (Lovable)** como ferramenta de produtividade no desenvolvimento
- Deploy funcional com autenticação de usuários

🔗 [Código-fonte](https://github.com/Cristianocsj/my-money-flow) • 🌐 [Aplicação ao vivo](https://crmoneymanager.lovable.app/auth)
